# Modern Health Suit (Pulse Matrix) 🩺

A professional, web-based health and nutrition dashboard powered by Python Flask and AI (Groq Llama-3 model).

## Features 🚀
- **Health Metrics Calculation:** Accurately calculates BMI, BMR, and TDEE based on user metrics (Metric/Imperial units support).
- **AI Clinical Reports:** Generates detailed, structured health, diet, and workout reports using Groq AI.
- **Interactive AI Chat Assistant:** Allows users to ask follow-up health questions and get instant clinical responses.
- **SQLite Database Integration:** Saves patient history and reports securely.

## Tech Stack 🛠️
- **Backend:** Python, Flask, SQLite, Gunicorn
- **Frontend:** HTML5, Tailwind CSS, JavaScript, Marked.js
- **AI API:** Groq Cloud (Llama-3 model)
